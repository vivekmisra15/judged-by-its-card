# Glossary (plain English)

- **Hugging Face**: a public website where people share AI datasets and models, like GitHub for AI.
- **Dataset card**: the documentation page that comes with a dataset (what it contains, where it came from, how to use it).
- **Metadata / YAML block**: the small technical header at the top of a card, often filled in automatically.
- **Tier**: our three outcome groups, low, medium, high, based on likes.
- **API**: a way for a program to ask a website for data directly instead of a person clicking.
- **API key**: a private password that identifies you to a paid service. Never share it or commit it to Git.
- **Zero-shot**: using a model as it comes, with no training on our own examples.
- **Baseline**: a simple method used as the bar to beat.
- **Logistic regression**: a simple, standard statistical method that weighs several numbers to pick a category.
- **Cross-validation**: testing a method on data it was not trained on, rotating which part is held back.
- **Confusion table**: a grid showing what the method guessed versus what was true.
- **Calibration**: whether "70% sure" really is right about 70% of the time.
- **Abstain**: to decline to answer when not confident enough.
- **Pre-registration**: writing down the plan and what would prove it wrong before seeing results.
- **Stratified sample**: picking equal numbers from each group instead of purely at random.
- **Virtual environment (.venv)**: a private folder of installed tools so this project does not disturb the rest of the Mac.
- **Git / repository**: a version history of the project's files. This project's repository is local only; nothing has been uploaded.
- **Base rate**: how common each outcome is in the real world (here about 90% of new datasets get no likes).
- **Rebalancing**: adjusting a model's probabilities to remove its built-in lean towards the common outcome, so every tier starts equal.
- **AUC**: a ranking score. Pick one positive case and one negative case at random; AUC is how often the method scores the positive one higher (50% chance, 100% perfect).
- **Correlation**: how closely two numbers move together, from -1 to 1 (0 means no link).
- **Exploratory analysis**: looking at results after the fact for possible explanations. Useful for ideas, not proof, because it was not planned in advance.
